# Contributing

We'd love your help with this book! There are several ways to contribute.

## Corrections

If you spot an error, please open an issue or submit a pull request with the fix. Typos, factual errors, code mistakes, and unclear explanations all count!

## New Content

If you'd like to add a new section or expand an existing one:

1. Check if there's already an open issue about it
2. If not, open an issue describing what you'd like to add
3. Wait for feedback from maintainers
4. Submit a pull request with your changes

## Writing Style

- Write clear, accessible English
- Use code examples to illustrate concepts
- Provide real-world scenarios when possible
- Include both attack demonstrations and defense strategies
- Always add appropriate content warnings for sensitive topics

## Pull Request Process

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/new-section`)
3. Make your changes
4. Ensure the book builds (`mdbook build`)
5. Submit a pull request

## Code of Conduct

Please be respectful and constructive in all interactions. We're all here to learn and share knowledge about web security.
